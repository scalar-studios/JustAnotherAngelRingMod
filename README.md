# JustAnotherAngelRingMod
Just Another Angel Ring Mod adds a simple Angel Ring to the game for Minecraft 26.1.2+.

It is designed to be lightweight and easy to use: equip the ring and take to the skies.
No huge progression tree, no complicated setup - just a clean, fun way to fly.

## Quick Info
- **Minecraft Version:** 26.1.2+
- **What it adds:** An Angel Ring Curio item
- **Goal:** Simple, convenient flight for everyday gameplay

Great for builders, explorers, and anyone who wants a little more freedom while playing.
